# tidytargets: Tidy Pipe-Friendly Grammar for Targets Pipelines

A tidy, pipe-friendly grammar for composing targets pipelines.
Internally it is based on targets factories, translating piped steps
into a dependency graph that can be deployed locally, on HPC, or in the
cloud.
